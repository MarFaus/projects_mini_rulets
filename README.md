# МЕЗОН Rouleaux — Веб-сайт Кондитерского Дома Мини-Рулетов

Интерактивный сайт-витрина и онлайн-бутик авторских десертов с интерактивным сборщиком сетов и формой бронирования.

## Структура проекта

- `index.html` — Главный каркас страницы и модальные окна
- `css/tokens.css` — Переменные дизайна (цвета, сетка 8pt, типографика)
- `css/base.css` — Сброс стилей, базовые элементы
- `css/components.css` — Стили компонентов (шапка, hero-экран, карточки, корзина)
- `data/content.js` — Все текстовые данные, категории и продукты
- `js/app.js` — Глобальное состояние приложения
- `js/modules/storage.js` — Работа с LocalStorage
- `js/modules/counter.js` — Анимированные счётчики статистики
- `js/modules/catalog.js` — Каталог с фильтрацией и поиском
- `js/modules/builder.js` — Интерактивный конструктор дегустационных сетов
- `js/modules/cart.js` — Управление корзиной и заказами
- `js/modules/modal.js` — Управление модальными окнами и уведомлениями
- `js/main.js` — Точка входа и инициализация

## Таблица изменений

| Что нужно изменить | Какой файл открыть |
|---|---|
| Цвета, шрифты, отступы | `css/tokens.css` |
| Тексты рулетов, цены, ингредиенты | `data/content.js` |
| Структуру блоков и секций | `index.html` |
| Логику корзины и скидок | `js/modules/cart.js` или `js/modules/builder.js` |
